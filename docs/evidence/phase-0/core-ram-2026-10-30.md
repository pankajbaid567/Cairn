## Notes

- Container cgroup memory excludes the Docker Desktop VM's own overhead (the Linux kernel, the Docker daemon and the file-sharing layer), so the VM needs more than the total shown here.
- `docker stats` subtracts only the inactive file cache. Active file cache and memory-mapped binaries still count towards it, which is why the `anon + shmem` columns are given next to it.
- One GB in the estimate and the ceiling is one GiB (1024^3 bytes), as Docker prints it.
