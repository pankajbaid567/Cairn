## What this means for Cairn

- **template1 carries the extensions.** Every database created with `CREATE DATABASE` inherits them. `cairn` and `cairn_dbos` (created by `cairn-db bootstrap`) both list vector, pg_search, pg_ivm, postgis, postgis_topology, postgis_tiger_geocoder, fuzzystrmatch and pg_stat_statements. Bootstrap's `CREATE EXTENSION IF NOT EXISTS` is therefore a no-op for `vector` and `pg_search` and only adds `btree_gist`. `/readyz` checks only the three required ones, so the extras do no harm, but they enlarge the attack surface of `public` (PostGIS functions, `postgis_tiger_geocoder` schemas). Phase 1 can switch to `CREATE DATABASE … TEMPLATE template0` in bootstrap if a clean database is wanted. Not changed here.
- **Auto-tuning follows the container memory limit.** The init script reads the cgroup limit and writes the tuning block to `$PGDATA/postgresql.conf` on first boot only. With the 1024m limit: `shared_buffers` 256MB, `work_mem` 15MB, `maintenance_work_mem` 64MB, `max_connections` 100. Design §4 assumed "defaults, 128 MB shared_buffers"; the real value is 256MB. Changing `CAIRN_DB_MEM_LIMIT` after the volume exists does not retune (run `make db-reset`). The spike harnesses raise `maintenance_work_mem` and `work_mem` per session as designed.
- **Healthcheck.** During first boot the entrypoint runs a temporary server that listens on the unix socket only. A TCP `pg_isready -h 127.0.0.1` therefore passes only after the real server is up. Measured: `make up-db` on an empty volume took 17.5 s to healthy.
- **Compose resolution.** The digest is written literally in `docker-compose.yml` (design §4 sketches `${PARADEDB_TAG}@${PARADEDB_DIGEST}`; a literal reference lets `scripts/licenses.py` and `docs/licenses.md` read it).

## How to re-check

```bash
docker buildx imagetools inspect paradedb/paradedb:0.26.3-pg18
docker exec cairn-db-1 psql -U postgres -X -A -t -c 'show shared_preload_libraries'
docker exec cairn-db-1 psql -U postgres -X -A -t -c "select name, default_version from pg_available_extensions where name in ('vector','pg_search','btree_gist')"
```

Bump procedure: pick the newest `*-pg18` tag on Docker Hub, take the index digest from `imagetools inspect`, change the `image:` line in `docker-compose.yml`, run `make db-reset`, `make up-db db-init`, and re-run the gates.
