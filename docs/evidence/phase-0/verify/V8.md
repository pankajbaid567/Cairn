## If the endpoint stops working
pnpm 10.8.1 uses the npm registry's bulk advisory API. If a later run fails with an endpoint error instead of a finding, `make audit-web` exits non-zero and says so; the fallback is `osv-scanner` on `apps/web/pnpm-lock.yaml` (pin its image by digest first). Treat only an exit caused by an advisory as a finding.
